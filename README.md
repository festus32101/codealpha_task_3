# Amazon Fine Food Reviews — Data Visualization

## Project Overview

This project focuses on transforming the Amazon Fine Food Reviews dataset into clear and informative visualizations using Python. The goal is to make patterns in customer ratings, review activity over time, and product popularity easier to understand.

The project demonstrates practical skills in data preparation, chart design, dashboard development, and communicating insights through visual storytelling.

## Objectives

- Visualize the distribution of customer ratings.
- Examine review activity across different years.
- Explore changes in average customer ratings over time.
- Identify products with the highest number of reviews.
- Combine key visualizations into a dashboard for easier interpretation.
- Present data insights in a format that supports understanding and decision-making.

## Dataset

The project uses the Amazon Fine Food Reviews dataset, which contains customer reviews and ratings for fine food products sold on Amazon.

**Dataset source:** [Amazon Fine Food Reviews — Kaggle](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews)

The original `Reviews.csv` file is not included in this repository because of its large file size. Download the dataset from Kaggle before running the script.

## Tools and Technologies

- **Python:** Main programming language.
- **Pandas:** Data loading, preparation, grouping, and summarization.
- **Matplotlib:** Chart customization, figure layout, and exporting visualizations.
- **Seaborn:** Statistical charts and visual styling.

## Visualizations

The project generates the following visualizations:

### 1. Rating Distribution
Shows the number of reviews for each star rating from 1 to 5, helping reveal the overall distribution of customer ratings.

### 2. Reviews by Year
Displays review volume over time to identify periods with higher or lower review activity.

### 3. Average Rating by Year
Shows how average customer ratings vary across years.

### 4. Top Products by Review Count
Highlights the products with the highest number of reviews in the dataset.

### 5. Combined Dashboard
Brings the main visualizations together into one figure, allowing viewers to examine rating patterns, review activity, average ratings, and product popularity in one place.

## Key Areas of Insight

The visualizations are designed to help answer questions such as:

- Which star rating occurs most frequently?
- How has review activity changed over time?
- How does the average rating vary by year?
- Which products have received the most reviews?
- What overall patterns can be observed in customer feedback?

The charts support descriptive analysis. Review counts do not necessarily indicate product quality, sales volume, or customer satisfaction on their own.

## How to Run the Project

### Requirements

Install Python 3 and the required libraries:

```bash
python -m pip install pandas matplotlib seaborn
```

### Setup

1. Download the Amazon Fine Food Reviews dataset from Kaggle.
2. Extract the dataset and locate `Reviews.csv`.
3. Place the CSV file in the location expected by the Python script.

### Run the Script

Open a terminal in the project directory and execute:

```bash
python task3_data_visualization.py
```

The script generates the charts and summary tables in the configured output directory.

This project demonstrates how Python visualization libraries can transform a large review dataset into understandable charts and a dashboard. By exploring customer ratings, review activity over time, and product review counts, the project helps communicate patterns that may guide further investigation and decision-making.
